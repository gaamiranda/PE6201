# 4. What it costs

Using the Class 5 three-layer model, our baseline is layer 1 token cost plus layer 2 expected fallback cost, multiplied by 8,000 claims per month, plus a US$500 per month fixed layer 3 deployment assumption. A failure costs US$7.60: a claims assessor at US$38 an hour for twelve minutes. Retrieval and tool fees are zero; the repository records no separate provider charge. We ship the model with a 12-turn step cap, a 22-call cap, a US$0.016 per run budget ceiling, and a US$1,000 per user per month spend limit, a guardrail, not a cost, that never enters layer 3. Prompt caching and reasoning-token adjustments were not used or measured.

google/gemini-2.5-flash-lite is the best model for our product. Its layer 1 cost is the second lowest, but it has the highest measured success rate, so once layer 2 is counted its cost per successful task is the lowest, at US$1.8014, or US$14,911.06 a month at our volume. The second and third models by success rate show the same lesson: mistralai/mistral-medium-3 has a layer 1 cost about two times higher than deepseek/deepseek-chat, but its final cost is still lower. Token price alone is not the decision variable; when a human claims assessor handles each failure, success rate drives the fallback cost.

Across a plus or minus 10 percentage point range, the measured decision is clear but not fully robust: a weak Gemini point at 66.32% and US$2.5614 per successful task is more expensive than measured Mistral at US$2.3062. Break-even is sharpest between the closest pair. DeepSeek is currently 50/76 = 65.79% and Mistral is 53/76 = 69.74%; DeepSeek would need to reach about 69.69% success to match Mistral's cost. An improvement of 3.90 percentage points changes the ranking.

Two of the four levers, the dependency rule and the descriptor rewrite, belong to the tool layer and are reported in §2; all three token levers were measured on scripted replay, so we assume the success rate did not decrease. Tool-block size, the first lever, was measured here: removing two rejected tool descriptors reduces input tokens by 96,288 and projected cost by US$0.009640 on the 76-trial replay, linearly, since the manual is re-sent each call. The fourth lever dominates. On mistralai/mistral-medium-3, reducing token cost by 5% changes total cost only slightly, while improving success rate by 5 percentage points reduces fallback cost by about US$3,040 per month, roughly one sixth of the model's monthly total. The token bill is small; the fallback bill is the system.
